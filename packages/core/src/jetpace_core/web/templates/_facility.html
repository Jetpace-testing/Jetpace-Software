{# The facility panel - the design's "Facility Overview". THE DESIGN DRAWS A FLOOR PLAN: five named zones at hand-chosen coordinates, device dots scattered over them. There is no room, zone or coordinate anywhere in this schema - a device belongs to a gateway and a gateway to a site - so those positions could only be invented, and an invented floor plan in front of a customer is a promise that the software knows where their instruments are. A gateway is the real grouping, and not a poor substitute for one: it is one serial bus or one converter, which on a plant floor is one area. So the zones are the gateways, the markers are the devices on them, and the layout is a grid rather than a plan. Same question answered - which parts of the facility are healthy - from the grouping that exists. Each marker is a link to its device, so the dots are not decoration and carry their own accessible name. Colour is never the only encoding: the name is in the link, and the legend beneath counts every state in words. #} {% import "_icons.html" as ico %}
